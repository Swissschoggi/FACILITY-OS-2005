# DESIGN CONSTITUTION

## Project identity

A Y2K Chrome Futurism × Sci-Fi Computer Interface portfolio.

The website should feel like a piece of futuristic computing hardware from an imagined 2005, designed with the technical capabilities and polish of today.

It is not a conventional portfolio template.

## Visual direction

The design combines two equally important directions:

**Chrome Futurism**
- Reflective chrome.
- Polished silver.
- Brushed aluminium.
- Translucent blue acrylic.
- Metallic gradients.
- Glossy highlights.
- Physical depth and bevels.

**Sci-Fi Computer Interface**
- Layered technical panels.
- Industrial controls.
- LCD-style displays.
- Segmented navigation.
- Status indicators.
- Technical diagrams.
- Dense but readable information.

Neither direction should become a superficial accent on top of a generic website.

## Design principles

1. Commit fully to the aesthetic.
2. Establish design tokens before implementing components.
3. Make every component feel physically and visually connected.
4. Use intentional visual complexity, not random decoration.
5. Prioritize strong composition over generic card layouts.
6. Preserve readability and accessibility.
7. Treat responsive layouts as designed experiences, not desktop layouts squeezed onto mobile.

## Content and factual accuracy

Use `./opencode-homelab-handoff/` as the sole source of truth for homelab facts.

Do not invent hardware, services, capabilities, uptime, security guarantees or infrastructure relationships.

Do not publish private IP addresses, credentials, internal hostnames, private domains or sensitive network configuration.

## Writing rules

- Never use em dashes (—).
- Avoid generic AI-generated marketing language.
- Avoid exaggerated claims.
- Prefer direct, technical, human writing.
- Do not use placeholder text in the finished website.

## Implementation rules

- Build a coherent design system before implementing pages.
- Use reusable components without making every component look identical.
- Use real content and actual infrastructure relationships.
- Make navigation, interactions and responsive behavior functional.
- Test the actual implementation in a browser.
- Do not declare completion based on code generation alone.

## Quality gate

The final result must be recognizably Y2K Chrome Futurism × Sci-Fi Computer Interface without explanation.

If removing the chrome, metallic materials and industrial interface elements makes the website look like a generic SaaS portfolio, the implementation has failed.
