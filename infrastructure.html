B1 Architecture TWO PLATES: NETWORK / 01 + COMPUTE / 02
Text description of both architecture plates

Plate 01, network organisation. A UniFi Dream Machine Pro serves as gateway, router, firewall and network controller. A USW-Lite-16-PoE switch acts as the core switch. One reported physical port on the core switch feeds an unmanaged downstream switch. Three UniFi nanoHD access points provide wireless coverage. Three network segments, Main, Guest and IoT, are configured logically on the Dream Machine Pro. Cloudflare Tunnel and WireGuard allow remote access; these are software paths.

Plate 02, compute and storage. The compute side is a Proxmox VE 9.1 virtualization host on Debian 13 that currently runs two virtual machines and nine containers; the individual guests are tabulated in the Proxmox rack bay in this page's platform section. The storage side is an Unraid 7.2.0 NAS that provides bulk storage on five 12 terabyte data disks plus a single ZFS cache, with no parity disk configured cause i'm a bad boy with too much storage. The storage relationship between them is an NFS share of the media volume that Proxmox and selected containers consume. Compute and storage are separate platforms; neither depends on the other for administration.
